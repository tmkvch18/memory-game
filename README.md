# Memory Game

Игра «Memory» на эмблемах клубов АПЛ: найдите все 8 пар карточек за наименьшее число ходов. Топ-10 результатов сохраняется в localStorage.

**Стек:** JavaScript, SCSS, Vite.

**Локальный запуск:**

```bash
npm install
npm run dev
```

Затем откройте адрес из терминала (по умолчанию http://localhost:5173/memory-game/).
